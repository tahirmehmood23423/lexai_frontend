# ═══════════════════════════════════════════════════════════════
# STEP-BY-STEP FREE DEPLOYMENT
# ═══════════════════════════════════════════════════════════════

# ── STEP 1: Database — Supabase (free, 500MB) ──────────────────
# 1. Go to supabase.com → create account → New project
# 2. Choose region closest to Pakistan (e.g. Singapore)
# 3. Go to SQL Editor → paste contents of database/schema.sql → Run
# 4. Go to Settings → Database → copy "Connection string (URI)"
#    → put in backend .env as DATABASE_URL
# 5. Go to Settings → API → copy "service_role key"
#    → put in backend .env as SUPABASE_SERVICE_KEY
# 6. Go to Storage → create 3 buckets:
#    - case-documents  (private)
#    - lawyer-profiles (public)
#    - client-uploads  (private)


# ── STEP 2: Email — Resend (free, 3000 emails/month) ───────────
# 1. Go to resend.com → create account
# 2. Add your domain OR use the free resend.dev domain for testing
# 3. API Keys → Create API Key → copy it
#    → put in backend .env as RESEND_API_KEY


# ── STEP 3: Google OAuth (free) ────────────────────────────────
# 1. Go to console.cloud.google.com → New project "LexAI"
# 2. APIs & Services → OAuth consent screen → External → fill form
# 3. APIs & Services → Credentials → Create OAuth 2.0 Client ID
#    - Application type: Web application
#    - Authorized redirect URIs: https://lexai.vercel.app/auth/callback
#                                http://localhost:5173/auth/callback
# 4. Copy Client ID and Client Secret → put in .env files


# ── STEP 4: Backend — Render.com (free) ────────────────────────
# 1. Push backend/ folder to a GitHub repo
# 2. Go to render.com → New → Web Service → connect GitHub repo
# 3. Settings:
#    - Build command:  pip install -r requirements.txt
#    - Start command:  uvicorn main:app --host 0.0.0.0 --port $PORT
#    - Instance type:  Free
# 4. Environment → Add all variables from backend .env
# 5. Deploy → get your URL: https://lexai-api.onrender.com
#
# ⚠️ Free tier sleeps after 15 min inactivity (first request takes ~30s to wake up)
# To keep it awake: use UptimeRobot (free) to ping /health every 10 min


# ── STEP 5: Frontend — Vercel (free) ───────────────────────────
# 1. Push frontend/ folder to GitHub repo
# 2. Go to vercel.com → New Project → Import repo
# 3. Framework: Vite → Root directory: frontend/
# 4. Environment variables → add VITE_API_URL and VITE_GOOGLE_CLIENT_ID
# 5. Deploy → get your URL: https://lexai.vercel.app
# 6. Update Google OAuth redirect URI with your Vercel URL
# 7. Update backend CORS to allow your Vercel URL


# ── STEP 6: Keep backend alive — UptimeRobot (free) ────────────
# 1. Go to uptimerobot.com → create free account
# 2. Add new monitor:
#    - Monitor type: HTTP(s)
#    - URL: https://lexai-api.onrender.com/health
#    - Monitoring interval: 5 minutes
# This prevents Render free tier from sleeping

# LOCAL DEVELOPMENT SETUP
# ═══════════════════════════════════════════════════════════════

# Terminal 1 — Backend
# cd backend
# python -m venv venv
# venv\Scripts\activate        (Windows)
# source venv/bin/activate     (Mac/Linux)
# pip install -r requirements.txt
# uvicorn main:app --reload
# → API running at http://localhost:8000
# → Swagger docs at http://localhost:8000/docs

# Terminal 2 — Frontend
# cd frontend
# npm install
# npm run dev
# → App running at http://localhost:5173

# For local PostgreSQL, install PostgreSQL and create a database:
# psql -U postgres
# CREATE DATABASE lexai;
# Then set DATABASE_URL=postgresql://postgres:password@localhost:5432/lexai
